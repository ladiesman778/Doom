# Doom

Mickhyle Dominick Bautista’s first-year BSIT portfolio.

Includes interactive browser adaptations of bankPinValidation, colorRange, and Meal Planner (UDDFITPLAN), plus original Java source downloads. The browser versions run JavaScript; the original Java files are unchanged.

## Website

https://ladiesman778.github.io/Doom/

To publish, select Settings > Pages > Deploy from a branch > main > / (root).

## Local preview

Serve this directory with a static HTTP server, for example `python -m http.server 8000`, then open http://localhost:8000. An HTTP server is needed for the source viewers.
